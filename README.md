 ## InfinityNews App
# About the app
* InfinityNews App is a mobile news application that allows users to read the latest news from different categories such as General,Technology,Sports,and politics news.Users can also bookmark their favourite article and they can also navigate between the pages using the navigation bar.

# Purpose of the App
The purpose of the InfinityNews App is to:
* Give users access to the news that is up-to-date.
* Provide simple and easy-to use interface.
* Help users to find specific types of news quickly through categories.
* Allow users to bookmark news to read later on.

## Design Consideration
 # Simple Design
 * The layout of the app is clean and easy to understand.
 * It includes icons that clearly represent each function.
 * Uses soft colours and also readable text.
   
# Easy for almost everyone
* Text is large enough for clear reading.
* Colour contrast helps users see items better.

# Good Performance
* Works smoothly on different screen sizes.
* Uses SharedPreferences to save bookmarks so users don’t lose them.
* Loads news quickly using RecyclerView.

# Easy to improve
* Built in Kotlin, making it easy to add new features in the future.
* Can connect to live news data using APIs like NewsAPI.org.
